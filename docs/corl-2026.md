# CoRL 2026 systems evidence

[Explore the 571 additions](../?view=practices&cohort=corl-2026-full-scan&dimension=overview) from the [687-paper accepted-paper inventory](https://www.corl.org/program/accepted-papers), reviewed 7 November 2026. The import adds 785 source entries and 412 source-mention memberships across 42 existing mechanism labels.

## Takeaways

**Timing is easier to recover than operational behavior.** Of the 571 included records, 325 contain timing information, 123 IPC information, 93 lifecycle information, 59 readiness information and 33 replay information. These are nonempty-field counts, including qualified reference and partial evidence. They measure this extraction's coverage; missing information does not establish that a mechanism is absent.

**Compute placement and asynchronous boundaries matter.** [AsyncVLA](https://arxiv.org/abs/2602.13476v1) splits a Jetson Orin edge adapter from an RTX 4090 workstation and associates returned embeddings with image-capture timestamps. Its 8 Hz edge inference, 5 Hz base inference and variable network delay describe distinct stages. [FingerViP](https://arxiv.org/pdf/2604.21331) likewise distinguishes 60 Hz pose streaming, 100 Hz teleoperation commands, 30 Hz cameras and 10.2 FPS policy throughput. A runtime should expose stage timing, queueing and observation/action age separately.

**Robot-facing interfaces vary.** The reviewed examples include ROS messages in AsyncVLA, ZeroMQ and shared-memory camera interfaces in [AutoDex](https://arxiv.org/abs/2606.23689v2), and HTTP plus in-process interfaces in [EagleVLA's released engine](https://openreview.net/forum?id=OckqYiY2QM). These examples support an integration strategy around existing transports; the scan does not establish transport market share.

**Recording is broader than a log file.** There is recording information in 297 entries, buffering information in 159 and provenance information in 122. These fields include demonstration collection and qualified offline artifacts. AutoDex combines multi-view media, robot state, calibration, outcomes and run traces across hosts. Its run/episode IDs, clocks and artifact references provide a concrete pattern for connecting native files through a run manifest.

**Lifecycle and provenance offer a product hypothesis.** AutoDex's persistent capture daemons and EagleVLA's managed server client expose different ownership, readiness and cleanup contracts. A shared experiment layer could connect process state, timestamped artifacts and outcomes while integrating those launchers. The survey provides integration examples; failure frequency, adoption demand and willingness to pay still require direct evidence.

## Scope and extraction

- Retrieved 617 full primary texts and 30 partial author sources. Forty primary-source access gaps remain.
- Final screening: 571 included, 62 excluded and 54 unresolved. Included records retain physical-evidence and scope qualifiers; two are simulation/reference robot interfaces and two have uncertain physical evidence.
- Luna low ranked candidates; Terra medium performed targeted full-text and appendix extraction; Sol low reviewed concrete code leads and source-scope issues. Ranking alone never excluded a paper.
- Completed 56 targeted code reviews, reused five prior reviews after matching paper hashes, and performed two identity reviews and 120 standalone source audits. Every final exclusion received source verification.
- Initial repository triage used 346 pinned file indexes because README prefetch failed. Deep reviewers fetched selected files directly. Another 218 late repository leads remain uninspected.

Review depth varies. Repository implementations can postdate the experiments or provide only reference infrastructure. Field-level evidence classifications and citations preserve that distinction. Mechanism labels added by this import are automatic **source mentions**, including qualified contexts; they do not assert deployment use. Unknown-only fields render as `-`.

## Preservation and maintenance

Original PDFs where retrieved, extracted text, source metadata, prompts, raw outputs, revisions and inspected code remain in the preserved research bundle outside this public repository. This repository contains public research summaries and source links. It omits source archives, local cache paths and internal follow-up queues.

To repeat the append-only import from the preserved derived preview:

```sh
python3 scripts/import_corl2026.py /path/to/preview/full/lab-research.json
node scripts/check_survey.mjs
```

The importer preserves existing records, source IDs and label memberships. Reimporting identical data is idempotent; conflicting IDs fail rather than silently overwriting evidence. A changed extraction should receive a deliberate evidence review before reconciliation.
